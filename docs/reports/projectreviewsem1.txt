Now, let's dicuss the WorkFlow of our System.
1. At first the system downloads the data set \\from kaggle.
2. Which is then loaded into Python.
3. Now Create a Panads dataframe. 
	\\Panadas DataFrame is two dimenstional dta structure like 2D array or table with rows and columns.
4. After which mapping of the annotations to image filenames is done.
5. Then Extract the images.
6. Now, the understanding of the 3D image data is done and the it is visualized,
   meanwhile the Segmenting of the lungs and cancer happens and the segmented image is saved in .npy file.
	\\.npy file is NumPy library file. NumPy is a python library taht supports large, multidientional array and matrices.
7. These segemnted images are uploaded to FloydHub
	\\FloydHub is a Deep Learning platform for productive data science teams.
8.Now training of the U-NEt model is done.
	\\U-Net is a convolutional neural network architecture that expanded with few changes in the CNN architecture.
9. Then Evautae the model.
10. Save thsi model with the format of .hdf5.
	\\HDF5 (Hierarchical Data Format is set of file formats designed to store and organize large amounts of data.)
11.Finally download the model from FloydHub.
